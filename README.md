# Chit Fund Management System - Backend API

RESTful backend service for the Chit Fund Management System built using Spring Boot.

## 🚀 Tech Stack
- **Framework:** Spring Boot 3
- **Language:** Java 17+
- **Database:** MySQL
- **ORM:** Spring Data JPA
- **Build Tool:** Maven

## 🔌 Core API Modules
- **Member Management:** Manage chit fund subscribers
- **Group Management:** Manage scheme schedules and group limits
- **Auction Engine:** Handle monthly bid amounts and winner calculations
- **Collection Tracker:** Monitor monthly installment payments
